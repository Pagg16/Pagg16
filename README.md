## 🚀 Проекты

### ☁️ Облачное хранилище  
🔗 https://github.com/Pagg16/cloud  
SPA для хранения и управления файлами.  
Реализованы авторизация, загрузка и скачивание файлов, работа с папками, древовидная навигация.  
**Стек:** React, Node.js, Express, MongoDB

---

### 🛒 Конструктор интернет-магазинов  
🔗 https://github.com/Pagg16/online-catalog  
Мой собственный проект — попытка создать универсальный конструктор e-commerce сайтов.  
Реализованы роли пользователей, админ-панель, уведомления о заказах через WebSocket, виртуальный скролл.  
**Стек:** React, Vite, Redux Toolkit, Node.js, Express, WebSocket

---

### 🖥 Десктопное приложение для парсинга  
🔗 https://github.com/Pagg16/Electron-parser-app  
Electron-приложение для парсинга маркетплейсов.  
Используются fallback-стратегии поиска элементов, эмуляция действий пользователя, логирование ошибок со скриншотами.  
**Стек:** Electron, Playwright, JavaScript

---

### 💬 Чат в реальном времени  
🔗 https://github.com/Pagg16/socket-chat  
Веб-чат с личными и групповыми диалогами.  
Реализованы комнаты, индикаторы набора текста, авторизация.  
**Стек:** React, Node.js, Express, Socket.io, MongoDB

---

### 🎨 Онлайн-редактор (Canvas)
